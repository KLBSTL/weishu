# 能天使 · 下班后的龙门

公开同人角色包 1.0.1，2026-11-13。主角为普通能天使，场景是《喧闹法则》之后的龙门日常；没有混入后续异格身份。适合轻松陪伴、角色问答和短故事。不是官方作品，未自动发布到任何网站。本版沿用用户指定的《能天使-下班后的龙门.png》原卡面，图像数据不重新编码。

本次只改口吻和原创示例：取消固定句数、固定安慰顺序和泛泛接续，增加接梗、回嘴、自己的立场与短而认真的回应。12组示例覆盖轻松、拒绝、纠错、结束话题和认真交流；示例是节奏参考，不要求复述。世界书的16条内容与时间线不变。

## 文件与导入

- **能天使-下班后的龙门.png**：可单独导入或分享的角色卡。封面、人设、开场、16条世界书、Ark提示预设与本说明都在同一文件内，兼有 `chara` 和 `ccv3` 载荷。分享时传原始文件，截图或压缩可能丢失元数据。
- **能天使.character.json**：可编辑的角色卡源文件，包含人设、3段已知经历、原创当前场景、12组原创示例、2个备选开场，以及16条内嵌世界书。
- **龙门日常.worldbook.json**：与卡内相同的独立世界书。PNG已内嵌，通常无需再次导入；若单独使用，请先停用对应内嵌书，避免同一条目重复注入。此文件采用character-book的entries数组结构，未实测的第三方客户端可能需要转换到其本地格式。
- **能天使.prompt.json**：ark的声明式提示词预设，5种场景、5组口吻配置和4个可开关附加提示。它不是SillyTavern可执行JS插件，也不伪装提供模型永久记忆或断网生成能力。
- **cover.png**：不含角色数据的纯封面；用于封面预览，不要把它当作可导入角色卡。
- **manifest.json**：交付文件的SHA-256与格式校验结果。

重启 ark 桌宠加载更新，在「人物 → 角色卡」导入该 PNG，再点击「使用这张卡」。卡内预设自动成为人物默认值，可在「设置 → 提示词 → 当前人物」查看和修改。已保存的人物设置优先，点击「恢复本层默认」可重新使用卡内预设。若要更新已有能天使并保留历史，导入前勾选「更新当前人物，保留记忆」。独立的提示 JSON 可用于旧版或手动编辑。

其他支持角色卡 V2/V3 的客户端可使用标准人设与世界书字段。卡内提示和说明分别存于 `data.extensions.ark_companion.prompt_preset` 与 `package_readme`，由 Ark 读取预设，第三方客户端的扩展读取未实测。

## 使用口径

默认玩家是一位与企鹅物流合作的联系人。“老板”是亲昵称呼，不自动赋予博士全部经历，也不表示玩家就是大帝。可以自行设置虚构身份与称呼。回复默认直接台词；普通问答先回答当前问题，后台闲聊与手动提问分开。长批次提示采用400字以上连贯正文、自然分段目标，实际长度和重复仍受模型影响。

世界书以关键词触发，只有时间线边界常驻；不会自动成为碎碎念来源。有关莫斯提马与姐姐的秘密保留当时的未知状态。人物设定和世界书是资料，不是玩家已经参与的经历；开场、示例和普通生活设想属于本包原创同人内容，不冒称原作台词。物品交接、动作完成和偏好更正优先服从已展示的对话。

提示词能约束表达，但不能替代应用的展示ACK、状态记录或请求恢复逻辑。卡内不含任意JS、HTML脚本、远程资源加载器、私人对话、API密钥或账号令牌。

## 保留封面与重建

在仓库根目录执行以下命令重建。脚本读取包内 `cover.png`，写入角色文本元数据，并逐字节核对非文本 PNG 块。

```powershell
node tools/build-public-card.mjs desktop-pet/cards/exusiai-lungmen-1.0.1
```

脚本复用产品PNG解析/导出、主体识别、世界书触发及提示预设校验，生成PNG、独立世界书和manifest；嵌入元数据时检查封面图像块不变。校验结果说明格式与行为通过，不等于模型永不重复或已完成所有第三方平台兼容测试。
