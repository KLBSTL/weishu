# 皮肤、动作与局外盟约图鉴草案

2026-10-11；用户授权实现并上传新的皮肤/动作素材，确认在干员详情逐个选择皮肤和开关动作，并要求开局前可查看盟约效果。本草案先于实现写入。

已有调研确认公开来源fexli/ArknightsResource有额外Front/Back战斗模型和build动作模型。目录候选不等于已下载或已渲染；当前程序只选择默认前后模型。先核验候选文件、骨骼/图集/贴图和浏览器支持，只有完整可用条目进入正式菜单与提交；来源及许可沿用现有素材说明。

外观按实际干员charId在本浏览器保存，普通/精锐共享。详情增加皮肤选择、动作开关及可用动作预览；默认外观保持原行为。皮肤只改变客户端模型/预览，不改变技能、命中时间、倍率、特质、盟约、经济或确定性随机流。替身按实际显示的干员身份选择，召唤物保留其既有模型。切换能即时反馈，错误/缺失资源回落默认；动作关闭时保持静态模型，战斗结算继续正常运行。具体首批名单及文件核验结果在实现后记录。

大厅/房间提供“盟约图鉴”按钮，局外读同一份当前盟约数据，列出图标、名称、激活门槛、效果和成员，可打开详情；不依赖创建或加入对局。沿用翻译和弹窗/详情组件，兼容窄屏。

验收：检查正式素材路径与解析、可选名单和动作列表；定向验证偏好保存/回落、切换与动作开关、局外按钮无需对局即可显示新盟约和效果，并进行浏览器实际查看。新素材与功能一同快进上传weishu，保留来源许可和原工作索引。不会以目录存在代替可用性验证。

## 本地实现和验证结果

18名扩展干员的38款额外战斗皮肤已经下载，所有38款均有Front/Back，37款有Base模型；113个模型的骨骼、图集区域及PNG尺寸/签名通过解析，没有缺失区域或下载错误。共339个素材文件和1个公开目录清单，86,207,852字节。来源固定为fexli/ArknightsResource的d7bdc0146f99f6fa88ecdc1bbf79021c012c21c5；中文皮肤名由官方格式skin_table的`@系列#序号`映射得到。详见 [素材说明](ASSETS.md)。谬因当前来源无额外皮肤条目，仍可控制默认动作。

干员详情/调配已接入皮肤选择、动作开关、正面/背面/可用基建动作和动画列表预览；本浏览器按干员保存，普通/精锐共享。关闭动作保留已选动作，资源结构失效/未知皮肤回落默认；加载异常在预览中提示重试或选择默认。外观资源走原引用计数缓存，退出预览释放使用引用。大厅和房间的“盟约图鉴”读取当前25种盟约，无需创建对局即可查看效果、门槛和成员，成员详情也可设外观。

`node tools/build-skins.mjs` 成功，使用已提交目录清单重新生成也成功；`node --test --test-concurrency=1 --test-reporter=spec test/ui/appearance.test.js test/render/assets.test.js`：32通过、0失败。包含保存与重新读取、普通/精锐共享、不同干员隔离、损坏/不可写存储、默认/额外Front/Back选择、未知/破损皮肤回落，以及原资源缓存与卸载验证。`node tools/i18n.mjs check --all --strict`：4个完整语言包均1199/1199，无缺失和错误。

浏览器在局外打开哥伦比亚效果及四本星极详情，实际渲染星极“奇工妙想”Front、Back/Attack和Base/Interact；切换动作、关闭/开启、刷新后保存均核验。440×820窄屏的弹窗在视口内，页面无横向溢出，模型显示；控制台无本轮模型错误。没有宣称逐帧查看全部113个模型或进行完整实战/长期平衡测试。截图在工作区ark/testing/skin-assets/appearance-preview-{desktop,phone}.jpg。
