# 天灾难度修改确认稿

确认日期：2026-10-17。来源：本聊天中的原始设计、用户对22项设计问题的逐项答复及最后4项边界确认。已无待确认设计项。

本文是已确认的设计规格，尚未据此修改游戏代码。

## 一、适用范围与基础

- 仅修改天灾难度，其他难度不变。
- 以终极难度为基础应用以下规则；保留终极难度自身的回合、单人/联机和属性加成。
- 移除旧天灾设计，包括生命×100、攻击×10、防御×10、法抗×3、95%减伤，以及五、六阶棋子库存翻倍。
- 时间均为战斗内时间。最大生命值指应用本场难度、回合及属性加成后的最大生命值；胄、管涉及的生命比例以对应领袖的生命上限计算，联机共享生命池保持一致。
- 以下规则不取消现有关卡预设援军和领袖原有技能，明确替换的能力除外。
- 第14回合与隐秘核心的生命倍率同样作用于频次生命单位，增加其击破所需的有效伤害次数；不排除余音、刺胄之弹等频次单位。
- 频次生命单位不受任何来源的减伤影响。每次有效伤害固定扣除1点频次生命，不因伤害数值、物理/法术减伤或其他减伤倍率而降低；第14回合的25%减伤、隐秘核心的50%减伤均不改变这一扣血规则。生命倍率仍正常作用于其频次生命上限。

## 二、道中：第1—13回合

### 移动速度

所有敌人的移动速度在终极难度对应数值上额外乘以1.5。

### 类型抽选与上下两路

- 游戏开始时，从现有常规敌人类型中抽选4种不同类型，将原来的3种扩展为4种。
- 加上特异类型，本局共5种候选敌人类型。
- 每回合从这5种候选类型中随机抽取2种不同类型，上路使用其中一种，下路使用另一种；不再让上下两路统一使用同一种类型。
- 本局候选的4种常规类型在开局确定，每回合只重新抽选两路的类型，不重新生成候选集合。
- 每一路的敌人数量与原规则一致，不因类型替换改变；其余出怪时间、间隔与路线沿用终极难度。

## 三、第14回合：最终攻势

所有敌人在终极难度第14回合数值基础上：

- 最大生命值乘以1.5。
- 受到的物理与法术伤害额外乘以0.75，即额外获得25%物理、法术减伤，与其他来源的减伤做乘算。
- 此项减伤不作用于元素伤害、真实伤害或生命流失。

## 四、第15回合：隐秘核心

- 所有敌人的最大生命值在终极难度对应数值上乘以2，替代此前确认的4倍生命。
- 所有敌人额外获得50%物理与法术减伤，即受到的物理与法术伤害额外乘以0.5，与其他来源的减伤做乘算；此项减伤不作用于元素伤害、真实伤害或生命流失。
- 覆盖领袖、敌方部件、预设援军及战斗中生成的敌方召唤物，同一个单位只应用一次。
- 第14回合的1.5倍生命及25%物理、法术减伤不延续至本回合。
- 不额外继承道中的移动速度×1.5；其余规则沿用终极难度，并追加以下能力。

## 五、隐秘核心「胄」

### 低生命能力替换

原能力“自身生命值低于20%时，受到的物理与法术伤害降低50%”替换为：

> 自身生命值低于最大生命值20%时，受到的物理、法术、元素及真实伤害降低80%；此效果不减免生命流失。

### 新增技能【钢铁洪流】

| 项目 | 规则 |
| --- | --- |
| 初始技力 | 0 |
| 技力消耗 | 50 |
| 回复方式 | 受击回复，每次独立的有效伤害回复1点技力 |
| 屏障吸收 | 完全被屏障吸收的伤害不回复技力 |
| 蓄力 | 3秒 |
| 优先级 | 低于其他技能，高于普通攻击 |

释放期间停止普通攻击及其他技能，蓄力期间不获得技力。蓄力完成后依次执行：

1. 单人战场召唤1只“帝国的甲胄”；双人合战场召唤2只，分别沿两侧路线进攻。复用关卡已有甲胄的出生点和路线，保留甲胄原有技能。
2. 立即为场上所有存活敌人增加相当于胄最大生命值1%的数值屏障，包含本次召唤的甲胄。允许多次施放累积，但【钢铁洪流】来源的屏障在每名受益者身上最多保留相当于胄最大生命值2%的数值。此上限只约束本技能来源，不占用或裁剪其他来源屏障。屏障持续至消耗完毕或本场战斗结束。
3. 使场上所有存活的“帝国的甲胄”获得异常状态免疫，包括原有援军及技能召唤的甲胄。免疫持续至本场结束，重复赋予不叠加。
4. 拥有该强化的甲胄被击杀时，胄流失自身最大生命值1%的生命；漏怪或其他非击杀离场不触发，同一只甲胄只触发一次。

异常状态免疫包括眩晕、冻结、睡眠、束缚、沉默、恐惧、浮空、强制位移。不包括寒冷，不免疫元素损伤积累、元素爆发及其效果。此免疫不包含属性减益，减攻、减防、减攻速、脆弱等仍正常生效。

## 六、隐秘核心「铳」

### 新增能力【代赎之罚】

铳自身嘲讽等级降低1级，作为本能力的常驻效果，不以三种护盾是否存在为条件。

铳受到来自我方单位的伤害时，检查三类“碎铳之簧”的护盾状态。伤害即使被铳的屏障吸收，也可以触发本能力。

| 生效条件 | 对本次伤害来源的效果 |
| --- | --- |
| 元素护盾仍存在 | 造成100点侵蚀损伤 |
| 法术护盾仍存在 | 每秒造成100点法术伤害，持续10秒 |
| 频次护盾仍存在 | 最终攻击速度乘以0.5，持续10秒 |

- 三项条件独立判断，可同时触发。
- 持续法术伤害不叠加，重复触发刷新至10秒。
- 攻速减半不叠加，重复触发刷新至10秒。
- 判断护盾本身是否仍存在，不以对应碎铳之簧的存活状态代替。
- 三种护盾均不存在时，满足同一受伤来源条件的每次受伤使铳额外流失2000点生命。
- 生命流失不属于“受到伤害”，【盲信之誓】等途径传递的生命流失不触发本能力。
- 本能力造成的伤害不得触发我方单位的反伤能力，防止反伤循环。

## 七、隐秘核心「管与弦」

### 新增共享主动技能【管弦合鸣】

| 项目 | 规则 |
| --- | --- |
| 技力池 | 管与弦共用一个技力池 |
| 初始技力 | 0 |
| 技力消耗 | 30 |
| 回复方式 | 攻击回复 |
| 共同蓄力 | 8秒 |
| 优先级 | 高于其他技能和普通攻击 |

### 技力回复

- 管或弦每次普通攻击为共享技力池回复1点技力。
- 技能攻击不提供上述基础回复；多段普通攻击每次完整攻击只回复1点。
- 管或弦的攻击使一只余音发生形态转换时，额外回复3点共享技力。此额外回复包含【裂管之奏】及【断弦之奏】造成的转换。
- 我方攻击造成的转换不提供额外技力。

### 蓄力完成

- 技力满足要求且可施放时，优先于其他技能和普通攻击开始共同蓄力，持续8秒。
- 蓄力期间两者不释放其他技能，也不进行普通攻击。
- 蓄力完成后，对全场我方单位各造成一次999点凋亡损伤，无视隐匿与迷彩。
- 损伤结算后，对所有正在凋亡损伤爆发中的我方单位执行强制退场，包括此前已处于凋亡爆发状态的单位。
- 强制退场不触发复活、不屈等免死或再部署机制，也不触发自身或其他单位的死亡类效果，包括“友方死亡时”类天赋及盟约。

### 余音死亡中断

- 共同蓄力期间，任何一只余音死亡，立即中断本次技能，不再结算全场凋亡损伤及退场效果。
- 中断时，管受到相当于自身最大生命值5%的真实伤害。该惩罚绕过所有减伤、屏障及单次伤害上限，保证实际扣除对应生命值；剩余生命不足时正常击倒。
- 中断后共享技能技力清零、不返还，管与弦立即恢复普通攻击及其他技能，重新积攒共享技力。

### 召唤物及特殊单位

- 本技能覆盖我方召唤物；装置类召唤物不受本技能影响。
- 战术家的战术点等单位，仍可按其原有机制恢复或复活。
- 强制退场不禁止之后重新召唤同类召唤物。

## 八、实现与验收边界

- 本设计中的“初动0”明确表示初始技力为0，从0技力开始通过对应回复方式积攒，不表示开场立即施放；适用于【钢铁洪流】与【管弦合鸣】。
- 所有新增规则必须在浏览器与服务端采用相同的战斗逻辑及确定性随机流程。
- 道中验收覆盖开局4种常规类型、特异类型、每回合两路类型不同及各路数量不变。
- 难度验收覆盖旧天灾强化和高阶库存翻倍移除、R14/R15各自倍率（含频次生命）、频次单位无视所有减伤且每次有效伤害固定扣1点生命、敌方部件与动态召唤物只强化一次。
- 领袖验收覆盖技力获取、技能优先级、施法停手与中断、屏障来源独立上限、状态免疫与属性减益的区别、伤害与生命流失区别、反伤防循环、全场强制退场不触发死亡类效果及召唤物例外。
- 保留当前本地定制：泥岩普通/精锐为“萨卡兹、坚守”，闪灵普通/精锐为“萨卡兹、助力”。
