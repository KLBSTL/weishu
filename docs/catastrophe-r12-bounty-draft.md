# 天灾R12高级首领悬赏实施草案

2026-10-17。来源：用户《天灾第12回合高级首领悬赏设计稿.md》，已授权实施；平衡数据仍待实战校准。
遵循 stronghold-protocol-design 设计规范。本文先记录范围，实施后补充当前验证结果。

## 已确认要求

- 仅天灾R12战前增加高级悬赏阶段，保留R3/9/11机变和R12普通波次。
- 11名首领加1名零赏金整合运动士兵；原R9池首领全部排除。每人只接受所选一张任务，额外出现1名目标，持续一场。
- 单人固定士兵0资金、3–6资金档1张、7–9资金档1张，展示3选1。
- 多人共享轮选，0/3–5/6–7/9资金档分别1/2/2/1张，六卡不重复且赏金和≤30。
- 用户补充确认：单人各档内部等概率；多人从87种合法六卡集合等概率抽一组。
- 沿用现有延后到账，完整最终击败后结算一次，R13休整到账；转阶段、召唤物与分裂子体不重复领赏。
- 所有目标漏怪扣1生命；11名首领只走下路；保持R12现实115秒/游戏230秒时限。
- 首领黑板、阶段与技能按原始级别0导入。四名首领基础HP/ATK分别：颂偶20000/900、术师30000/350、骑士40000/1400、木裂60000/700；DEF/RES不变，再叠本轮倍率。
- 木裂自我泯灭立即解除恐惧并在整个状态（含延长）中免疫恐惧，结束后恢复可恐惧。
- 术师本体终死7秒后召饮泣之刺，非首要目标、不阻止结局，已结束不补出；只本体支付5资金。
- 蒸汽骑士包含怒守/誓死优先级、阶段转换、无敌空中炮击和返回地面路线；爱国者光环与颂偶全场伤害限本玩家战场。
- 不额外提供地雷、废热喷口、骑士骨血等援助；扎罗继续现有实现，不添加血债账款系统。

## 待核验与实现顺序

1. 核对当前悬赏卡数据、R12切入点、共享轮选/重连、出怪插入、最终死亡奖励及超时逻辑。
2. 用官方敌人数据库、手册和PRTS核对7名新首领及子体，补齐核心技能、阶段、动画与素材；缺失定义明确标注假设。
3. 将新增生成输入写入独立工具模块，由 `tools/build-data.mjs` 重建，禁止手工修改生成JSON。
4. 测试30种单人集合、87种多人集合、R9完全排除、天灾限定、原阶段不变、单次奖励/R13到账/漏怪/超时。
5. 为每名新增首领写实际战斗测试；测试木裂跨阈值和恐惧、蒸汽骑士炮击返回、术师延迟子体及场地隔离。
6. 浏览器/Node确定性、资源、静态与翻译检查，更新文档与黄金结果审计；保持之前暂停的AI工作。

## 实施记录

已实现独立12卡池、30/87集合等概率抽取、R12回合接入与原轮选流程；首领下路单体、漏怪1生命、完整击杀一次奖励与R13到账。
七名新首领的核心技能、复生与状态已接入，四名原有目标复用本地实现。加入9个模型及复生/阶段动作映射。
木裂免恐惧的延长时长、术师非首要子体和蒸汽骑士怒守延后炮击均有真实战斗测试。
新增敌人使原黄金测试按敌人排序分配的混编场景变化，重建在独立验证副本进行；不覆盖之前暂停的AI工作与源目录黄金文件。

规则、来源及明确的局部时序假设见[设计§36](design/advanced-bounties.md)。另补查了最远高台投枪的蓄力和怒守/誓死同时就绪的优先级。
