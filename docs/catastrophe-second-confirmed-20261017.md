## 二、隐秘核心胄：【钢铁洪流】重做

| 项目 | 规则 |
| --- | --- |
| 适用范围 | 天灾难度隐秘核心胄 |
| 初始技力 | 0，需要积攒后释放 |
| 单次消耗 | 固定50点 |
| 技力上限 | 150点，相当于最多储存3次技能费用 |
| 回复方式 | 每次独立有效HP伤害回复1点；完全被屏障吸收的伤害、生命流失不回复 |
| 蓄力 | 1秒，替代原3秒 |
| 释放优先级 | 低于其他技能，高于普通攻击 |
| 内置冷却 | 本次技能释放完成后开始计时，持续5秒；期间不再次释放本技能 |

### 技力与强化判定

- 开始释放时，先记录扣费前的技力，用于本次强化判定，再扣除50点技力；剩余技力保留。
- 蓄力期间停止普通攻击、其他技能及技力回复，沿用此前规则。
- 冷却期间仍按正常受击规则积攒技力，最高150点；冷却结束且满足原有施放条件与优先级时，才可再次释放。

| 释放前技力 | 单人召唤 | 双人合战场召唤 | 本次每名受益者增加屏障 |
| --- | --- | --- | --- |
| 50—99 | 1只 | 2只，两侧各1只 | 胄最大生命值1% |
| 100—149 | 2只 | 4只，两侧各2只 | 胄最大生命值1% |
| 150 | 2只 | 4只，两侧各2只 | 胄最大生命值5% |

### 技能结算

1. 蓄力完成，按上述表格召唤“帝国的甲胄”，复用本关既有出生点与两侧路线，保留甲胄原有能力。
2. 立即为场上所有存活敌人增加对应数值屏障，包含本次召唤的甲胄。
3. 【钢铁洪流】来源屏障在每名受益者身上的剩余数值，累计上限改为胄最大生命值的10%，替代此前第二次修改稿的5%（初版为2%）。与其他来源屏障独立计算，持续至消耗完毕或本场结束。普通释放单次增加1%、150技力释放单次增加5%的数值保持不变。
4. 场上所有存活甲胄获得此前确认的异常状态免疫：眩晕、冻结、睡眠、束缚、沉默、恐惧、浮空、强制位移。寒冷、元素损伤、元素爆发及属性减益不在免疫范围，持续至本场结束，重复赋予不叠加。

### 甲胄被击杀联动

- 本场每有一只“帝国的甲胄”被击杀，胄流失自身最大生命值0.5%的生命，替代原1%。
- 覆盖所有甲胄，包括预设甲胄、技能召唤甲胄及尚未被本技能赋予免疫强化的甲胄。
- 同一只甲胄只触发一次。漏怪不触发。
- 继续沿用已确认的固定领袖血池份额规则，保证该0.5%生命流失不被减伤、屏障或单次伤害上限抵消。

## 三、隐秘核心管：半血能力

- 天灾隐秘核心管首次低于最大生命值50%时，触发一次半血能力，每场仅触发一次。
- 删除原要求中提及的“半血后获得10%物理与法术闪避”；实施时先核查实际数据与执行路径。当前本地代码虽有概率参数，尚未发现对应低血闪避实现，不得误删其他领袖能力。
- 半血触发时，共享技能的正常技力消耗立即、永久由30点降低至20点，即使本次免费合奏随后被打断也不恢复。
- 半血能力额外安排一次免费的【管弦和鸣】：不消耗技力，自然结束后不清空原有共享技力。
- 如果正在释放其他技能，等待该技能释放完成后再开始免费合奏；不强行打断当前技能。
- 如果已经在合奏，将免费合奏排在当前合奏之后追加一次，不重置或延长当前合奏的10秒时长。
- 免费合奏被余音死亡打断时，仍清空共享技力，并执行相同的5%真实伤害惩罚。

## 四、共享技能【管弦和鸣】重做

本稿统一采用用户本次名称【管弦和鸣】，对应旧稿中的【管弦合鸣】。

| 项目 | 规则 |
| --- | --- |
| 技力池 | 管与弦共用 |
| 初始技力 | 0，需要积攒后释放 |
| 正常消耗 | 30点；管首次半血触发后永久改为20点 |
| 回复方式 | 攻击回复 |
| 原8秒蓄力 | 取消 |
| 新效果 | 直接进入10秒合奏 |
| 优先级 | 高于其他技能与普通攻击，沿用原规则 |

### 技力回复

- 管或弦每完成一次普通攻击，共享技力增加1点。多段普通攻击每次完整攻击仅加1点，技能攻击不提供基础攻击回复。
- 管或弦的攻击使余音转换形态时，额外增加3点共享技力；【裂管之奏】和【断弦之奏】造成的转换也计入。我方造成的转换不计入。
- 整个10秒合奏期间，管与弦停止普通攻击、其他技能及技力回复。

### 合奏与强制退场

1. 开始合奏时立即检查一次全场我方单位，已经处于凋亡爆发状态的单位立即强制退场。
2. 合奏第1至第10秒各结算一次全场100点凋亡损伤，共10次，无视隐匿与迷彩。替代原蓄力结束后一次999点凋亡损伤。
3. 整个合奏持续期间，只要符合条件的我方单位进入凋亡爆发状态，立即强制退场；不等待下一次每秒损伤结算。
4. 强制退场不触发复活、不屈等免死或再部署机制，不触发自身、友方的死亡或击杀类效果。
5. 继续覆盖我方召唤物；装置类召唤物不受影响。战术点等单位保留原有恢复例外，不禁止之后重新召唤同类召唤物。

### 余音死亡中断

- 合奏期间有任意余音被击杀，立即中断当前这一次合奏，取消其剩余损伤与强制退场监测。
- 管受到自身最大生命值5%的真实伤害，绕过全部减伤、屏障与单次伤害上限，保证对应实际扣血。
- 无论正常合奏还是半血免费合奏，被打断时共享技力均清零，管与弦立即恢复原有行动。
- 中断针对当前合奏；半血已经排队的免费合奏仍按上述排队规则执行，不把当前一次的打断视为取消半血能力。
