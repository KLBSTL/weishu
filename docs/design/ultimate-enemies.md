# DESIGN §35 — 终极三类敌人与场外自选

Part of [DESIGN.md](../DESIGN.md). 2026-10-17 用户确认；[草案与验证记录](../ultimate-three-enemies-draft.md)。

## 35. Ultimate groups and field selection

### 35.1 类型与回合

火力10组、突破16组、召唤10组加入单人/多人终极与天灾的 R1–13 随机池；低难度不变。
完整 N/E/S、权重、起止回合在 `tools/ultimate-enemies-data.mjs`，逐行对应用户《终极难度三类敌人设计稿.md》。
终极仍抽3种，天灾仍抽4种，日程仍按每种3槽、其余特异填充；R14/15 抽到新增类型时使用原版特异护卫候选。
强化版不早于 R8；幽灵限 R1–4、幽灵组长限 R8–10。纯子体组只保留 R3–7 畸变赘生物，不增加恶性瘤整组。
木裂战士没有额外冲撞/无法阻挡，散华没有常驻隐匿。同组保持单一主伤害类别，飞行种子为物伤；不攻击的幽灵可与血巫同组。

### 35.2 分路预算修复

先确定最终分路 N/E/S，再执行移动类别互斥和逐批计数。原模板常量敌人保留。
`B=f32(f32(n*P(template))/factor(template))`，`U=f32(P(enemy)/factor(enemy))`，
数量 `clamp(roundHalfEven(f32(B/U)),1,5)`。`P=HP+5*ATK+3*DEF+3*RES` 使用基础属性，沿用 float32 各步运算。
间隔 `max(n*原间隔/新数量,0.05*n*原间隔)`，批次开始时间、时间窗和路线索引保持模板。
用户确认已有敌人保留原 factor，新敌人暂用1；不加入回合强化属性，也不将整波预算分别重复分给两条路。

修复前天灾先用另一套敌人过滤批次和计算数量，再只换 enemyKey，可能丢掉另一移动类别的批次或让强敌继承弱敌数量。
现在最终分路直接解析原模板，因此使用对应地面/飞行路线，预览和实战一致。
2026-10-17统计确认保留原预算；2026-10-19召唤组改为下述共池分配，旧逐回合数量不作为新版数量承诺。
战力代理仅核对计数，不代表通关率或完整平衡评估。

### 35.3 连续母体预置上限

每场每回合按批次时间、原序号累计；运行中的周期召唤与死亡分裂不计预置额度。

| 母体（含强化版） | 回合 | 上限 |
|---|---|---:|
| 变异巨岩蛛、爆鸣/美声水手长 | 6–7 / 8–10 / 11–13 | 2 / 3 / 4 |
| 枯朽/腐败萃聚使徒 | 8–11 / 12–13 | 2 / 3 |

普通/强化同家族共享全场额度，两路不重复发放。持续母体目标为原批次数量2倍，分裂母体目标不翻倍。
按有效路线汇总一次原预算，先按出场顺序支付母体，再把余额按原子体批次预算占比分配。
子体计数战力乘0.75，向下取整，母体/子体每批最多5，零预算不强补，取整/封顶余额可以剩余。
母体额度耗尽后不再逐批免费补怪，余额只进入已有子体批次。原时间窗保留，以最终数量重算间隔。
子体实战属性及动态召唤/死亡分裂的数量、频率和周期均不变。
血巫组、腐败使徒组保留稿中待平衡说明。

### 35.4 场外自选与素材

阿斯卡纶、贝洛内已有完整技能实现，本次新增克莱门莎三技能实现。均可填五本/六本自选槽，沿用自选练度规则，
不增加正式商店棋子或棋子特质。贝洛内只有叙拉古；阿斯卡纶、克莱门莎只有协防。
克莱门莎基础属性/技能黑板来自官方表；额外机制核对
[PRTS](https://m.prts.wiki/w/%E5%85%8B%E8%8E%B1%E9%97%A8%E8%8E%8E)：物伤概率倍率、前方减伤、侵蚀、放逐运输、漩涡和侵蚀爆发触发弹药轰炸。
三技能普通攻击不耗弹，目标标记1秒，区域占用3.5秒，其间每秒一次共3轮轰炸。

原正式棋子皮肤范围仅为三人增加白名单例外。新增3个默认 Base 模型和阿斯卡纶1套额外时装（前/后/基建）。
[固定素材版本 de6cfb3](https://github.com/fexli/ArknightsResource/tree/de6cfb30ed1d41d9102d93e8ea400fc0cefc8ff7)
中贝洛内、克莱门莎没有额外时装，保留默认外观。不引入其他场外干员的额外皮肤。

`[ASSUMED]` 现有表缺少细节时：血巫爆炸半径1.5，火球衰减以出生点距离线性估算，腐败使徒每次召3只（沿用枯朽版本），
放逐拾取采用方形中心判定，缺失活动特殊地形使用现有地面通行规则。所有已知关键能力实际执行，不以只有属性代替。

### 35.5 反装甲步兵伤害倍率修正

反装甲步兵与组长首发榴弹主目标、溅射均造成 200% 攻击力的物理伤害；后续近战为 100%。
基础攻击力分别为 500、750，因此未计防御和回合倍率时，榴弹分别为 1,000、1,500，近战分别为 500、750。
修正旧实现倍率颠倒和溅射少算的问题，保留已有移速增加 200% 与攻击切换流程。
来源及验证：[修复记录](../rpg-damage-fix-20261018.md)。

### 35.6 2026-10-19平衡调整

单人/多人终极及天灾R1—13：火力编组实际攻击力乘0.9，派生普通/强化火球同样只乘一次；火球漏怪免LP，
本体仍正常扣血。伤害/灼燃机制与既有击杀、漏怪及完美统计口径保留。突破幽灵与幽灵组长初始/最大生命乘0.8。
上述削弱不改计数战力，不影响其他类别、首领或悬赏中的同名敌人；来源标记经子体和联防保留。
欺凌者最早R6（原突3在R4—5改染污躯壳），倾轧者最早R10（原突8在R8—9改欺凌者），N/E与权重不变。
召唤预算与上限见§35.3。完整确认与验证：[实施记录](../ultimate-balance-20261019.md)。
