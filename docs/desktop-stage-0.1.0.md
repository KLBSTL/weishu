# 桌宠阶段版 0.1.0

2026-11-12，发布在 `KLBSTL/weishu` 的 `dev` 分支。提供可使用的桌宠、人物管理和公开能天使角色包；游戏仍沿用原版本。本阶段为源码分发，尚未制作独立安装器。

## 安装与使用

需要 Windows、PowerShell 7 和 Node.js 22.16 或更高版本。在仓库根目录运行：

```powershell
npm ci --ignore-scripts --no-audit --no-fund
pwsh -NoLogo -NoProfile -File ./启动桌宠.ps1 -Check
pwsh -NoLogo -NoProfile -File ./启动桌宠.ps1
```

启动器首次自动安装锁定的 `dsh-pet 0.4.1` 依赖；桌面运行时按需下载 Electron，需要网络。第一次打开设置后，在「API连接」选择直连 API，或选择本机 DSH 并填写可执行文件路径。DSH 官方账号模式需要用户自己安装并登录官方组件；渠道模式使用用户自己的兼容接口配置。仓库不附带账号、密钥、私人角色卡或聊天记录。

在「人物 → 角色卡」导入 [能天使 PNG](../desktop-pet/cards/exusiai-lungmen-1.0.0/能天使-下班后的龙门.png)，然后点击「使用这张卡」。PNG 已内嵌 16 条世界书、4 个提示块和包说明，导入后自动使用卡内提示默认值。在「设置 → 提示词 → 当前人物」可预览、修改并保存；已保存的人物设置优先，恢复本层默认后重新读取卡内预设。独立 `能天使.prompt.json` 留给旧版或手动导入使用，不必再次绑定相同世界书。[角色包使用与来源](../desktop-pet/cards/exusiai-lungmen-1.0.0/使用与来源.md)说明适用时间线、封面与原作依据。

默认个人数据在 `desktop-pet/state`，后台测试数据在 `desktop-pet/validation-state`，两者均被 Git 忽略。可用 `-DataHome` 指定其他目录；自选目录请放在仓库外，或自行设置忽略规则。停止和重启需要使用同一组目录、端口参数：

```powershell
pwsh -File ./启动桌宠.ps1 -Stop
pwsh -File ./启动桌宠.ps1 -Restart
pwsh -File ./启动桌宠.ps1 -Headless -Port 3099
pwsh -File ./启动桌宠.ps1 -Headless -Port 3099 -Stop
```

## 本阶段包含

- 直连 API 与本机 DSH 通用设置；人物和会话隔离、历史持久化、已展示内容确认与重启接续。
- 手动提问优先；后台缓存补货、请求排队、限流退避和本地缓解。短时断网可使用已生成缓存；缓存耗尽时给出简短状态反馈，不伪造新模型回复。
- PNG / JSON 角色卡导入导出、世界书作用域与主体隔离、可预览的提示词预设草稿导入导出。
- 吊坠与单面板窗口、中文输入、切换动画、分页、减少动效和空闲时停止无效刷新。
- 能天使公开同人包：带元数据 PNG、可编辑 JSON、世界书、声明式提示预设和封面。不是可执行插件。

## 实测与边界

阶段原稿相关回归 209/209 通过、零跳过；隐藏桌面 120 轮操作和 12 次连续反转通过，窗口数量保持 2，空闲时无额外刷新报告。隐藏测试检查功能、泄漏迹象和动画执行，不代替真实桌面的流畅度观感。

公开能天使卡的官方与原渠道各完成 16 条被动、8 条主动和 8 问采样。官方主问答中位数/最大值约 1.92/4.21 秒，渠道约 13.68/41.66 秒；这是该次样本，不能当作所有账号和时段的服务保证。两侧被动与主动合计缓存命中均为 23/24。主采样的报告导出断言曾报错，完整内容已收齐；后续另做同会话重启补验，官方 19 项、渠道最终 20 项通过。渠道较早补验出现 429 和超时并触发本地缓解，保留为已知波动。

修复了普通卡跨人物私有资料隔离和提示设置加载竞态。长文 400 字目标尚非稳定保证，重复、口吻与缓存耗尽后的长尾仍可改善。模型没有永久可靠记忆，DSH 接续仍受上下文边界和实际展示状态约束。

## 发布副本验证

发布副本使用独立依赖和本地模拟接口验证，不重新发送私人资料或调用外部模型。最终相关回归 **179/179 通过，零跳过**（142.6 秒）；公开 PNG 实际导入与内嵌提示默认值 **5 项通过**，94 个提交内脚本语法检查通过，角色 ZIP 的 6 个文件哈希全部匹配。首次建档、后台启动、鉴权状态接口和停止后保留配置已验证。此处 179 项仅为随发布携带的桌宠相关测试，原稿 209 项还包括工作区文档等校验。

发布适配中补齐了测试辅助文件、仓库相对路径与异步草稿保存后的界面等待。沙箱临时目录曾拒绝文件替换，最终结果来自正常权限下的隔离本地测试。可复验命令：

```powershell
node tools/build-public-card.mjs
node tools/check-public-card.mjs
$env:SP_E2E = '1'
$env:CHROME_PATH = 'C:/Program Files/Google/Chrome/Application/chrome.exe'
# 先正常启动一次以安装原生窗口补丁，再停止桌宠。
# 若启用原生窗口测试，指定已安装的 Electron；DSH 测试需指定本机 DSH。
# $env:DSH_PET_ELECTRON_PATH = '<Electron 可执行文件>'
# $env:SP_DSH_EXECUTABLE = '<DSH 可执行文件>'
$env:SP_PWSH_EXECUTABLE = (Get-Process -Id $PID).Path
node --test --test-concurrency=1 test/companion*.test.js test/desktop*.test.js test/ui/*.test.js
```

DSH 集成测试使用本地模拟服务，不消费官方账号模型请求。没有可选运行时的环境会跳过对应集成测试；检查汇总中的 skipped，不能将跳过视为通过。

## 下一阶段：先美化，再逐步优化

先提交视觉草案，确定一套配色、面板层级、留白和字体尺度，再实现吊坠材质与光影、角色卡/气泡排版、面板切换和滚动手感。保持减少动效模式与文字可读性，先交付可使用的一版视觉效果。模型测速、重复率和更激进的性能优化按实际问题继续处理，不作为美化开始的前置任务。

人工桌面验收建议连续使用 40–60 分钟，观察吊坠摇摆及回弹、快速开合反向动画、滚动与分页、中文输入和焦点、气泡遮挡、DPI/多屏边缘位置，以及减少动效开关。记录触发动作和复现步骤；后台功能测试已覆盖的路径无需反复手测。
