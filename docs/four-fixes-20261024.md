# 访问团、召唤波次、禁用与隐秘入口修订

状态：用户已授权实现并尽快上传，先保存草案；以下为已核验事实与实施口径，尚未实现的部分不视为通过。

## 来源与已确认要求

- 用户要求核对访问团防御/法抗成长、修复召唤组过少、严格处理纯小盟约棋子、R14首领胜利后直接进入隐秘。
- 本地官方敌人黑板 `enemy_1387_winshd`：`ColdShield.interval=3`、`max_stack_cnt=10`、`def=0.1`、`magic_resistance=5`。并非受到伤害触发；[持盾长说明](https://prts.wiki/w/访问团持盾长)也明确每3秒成长。当前注册为“没有封冻/供暖器”而只保留基础属性，遗漏了无供暖器时仍然生效的成长。
- 原召唤预算按 `routeIndex` 分池，但模板经常每批有独立路线；各池不足单价后直接归零。四种单/多人终极、天灾各100种子，分别有9/9/17/17个波次的召唤组部分仅1–2名预置敌人；其中终极9/9个为整轮仅1–2名，天灾还有另一侧其他类型敌人，不能把该部分数量误称整轮数量。
- 莱恩哈特普通/精锐只有迅捷、精准两个自然小盟约，当前软禁判定要求大盟约，因此两者全禁仍留池。
- 当前隐秘入口还要求激活层数超过350/1200、队伍LP大于1；用户要求取消这两项附加门槛。

## 实施口径

1. 为现有访问团持盾者补全每3秒1层、每层防御+10%/法抗+5、最多10层。无受击加层，不给其他访问团成员追加该能力。现有地图没有紧急供暖器，按供暖器范围外处理；不虚构供暖器或封冻地形。本轮不扩展地图环境系统。
2. 召唤预算按同一入口分区（上/下）及移动类别汇总，每个有效模板批次预算只计一次。母体先支付，保留原全场家族上限；子体先按原批次预算占比取整，再将可支付的整数余量分配回未满批次，单批最多5，保留原时点、路线和时间窗。总预算不超支，母体运行时召唤、属性不变，不无预算强补。
3. 纯小盟约干员：全部自然小盟约被过滤时禁用；只禁其中部分仍保留。硬禁、单一大盟约软禁、有大小盟约者原全标签规则均保留。正式卡池和自选共用判定，默认1/3/5不变，同步弹窗说明与翻译。
4. 有隐秘关卡及首领配置的模式，在第14回合击败当前首领即进入第15回合隐秘，不再检查层数和LP门槛。战败不进入，仍以实际胜负判定，隐秘不会循环。没有隐秘关卡/首领的模式不凭空新增敌人。
