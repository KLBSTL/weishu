## 拟实现行为

1. 按用户最新要求，只处理卫戍中实际能使用的角色。名单必须由正式棋子、实际补位映射与合法自选入口核验，不以素材源目录或资产缓存中的角色数作为可用证明。来源无额外服装的保留默认皮肤，不虚构素材。
2. 下载骨骼、图集及图集实际引用的全部贴图；新增原始下载核对Git blob摘要，规范化图集后逐模型解析。缺失或不支持的模型不得静默加入菜单。
3. 双方向角色需要对应Front/Back；原本就只有单方向的角色允许沿用同一战斗模型的既有朝向规则。基建模型只用于动作预览。数字后缀战斗形态不当作额外服装混入列表。
4. 补上默认皮肤的基建动作，新增皮肤继续提供其各自动作。详情仍逐人选择皮肤、正背面/基建和具体动作；普通与精锐共享外观偏好，角色之间独立。
5. 保持战斗出手时间、伤害、盟约、经济和确定性随机流不变；保留地图及材质恢复内容。离线资源进入正式本地资产清单，清单必须可仅由仓库内资源重建。
