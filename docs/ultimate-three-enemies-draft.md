# 终极三类敌人、分路预算与场外自选扩充草案

2026-10-17。状态：用户已授权实施及上传；以下区分确认要求、现状和待验证项。

## 来源与确认要求

- 用户提供《终极难度三类敌人设计稿.md》：终极 R1–13 增加火力、突破、召唤候选组，按逐组回合范围、权重与 N/E/S 槽位抽选；保留原模板批次、时间窗和全局类型日程。
- 数量按每个原始批次的预算重新计算，沿用 float32、银行家舍入及 1–5 数量边界；地面与飞行是替代关系，不能重复花费预算。
- 连续召唤母体按每场每回合的预置数量限额，满额时整批替换为该组普通子体并重算数量；部分剩余额度只截断，不补预算。运行中召唤不受该预置限额影响。
- 血巫组、腐败使徒组存在稿内已注明的预算风险，本次先保留设计，不声称已完成平衡。
- 核对 R4–7 过强和上路过少的波次，修正分路替换之后沿用旧敌人数量及旧移动类别过滤的问题。
- 场外自选增加阿斯卡伦、贝洛内、克莱门莎；贝洛内仅叙拉古，另外两人仅协防，不进入正式商店棋子池；同步加入这三人的可用皮肤。
- 用户已确认：缺失的逐敌计数系数先沿用项目已有系数，新敌人暂用 1；这一假设须在实现和记录中注明。

## 已核验现状

- `server/match/waves.js` 先用总波次敌人过滤移动类别并计算数量，再替换天灾上下路敌人；替换后没有重新计算批次预算。
- 自选已有阿斯卡伦、贝洛内技能文件；克莱门莎在生成器中明确排除，需核验官方数据与完整技能支持。
- 当前额外皮肤目录限制正式棋子；本次仅为上述三名用户指定自选干员增加例外，保留其他范围限制。
- 原工作区存在暂停的 AI 改动；发布继续使用隔离索引和已发布 main 为基线，不夹带暂停内容。

## 拟实现

1. 在数据生成输入中定义三类分组、回合边界、权重和召唤上限，补齐官方基础属性、技能与素材，统一生成游戏数据。
2. 抽选先筛回合范围；每条分路直接使用该路最终抽选结果解析原模板，保持移动类别互斥；按新敌人重算每个批次数量和间隔。
3. 连续母体在按出怪时间排序的预置批次上累计限额，回退子体也使用原始批次预算。
4. 补齐自选干员技能、盟约、立绘/战斗模型/皮肤入口；不新增正式棋子特质。
5. 更新玩法说明、数据说明和实施记录，在隔离发布快照中重建黄金结果并上传。

## 实施记录与验收（2026-10-17）

已实现：34个候选组（火力10、突破14、召唤10）、新增敌人的实际技能、母体预置限额、逐批预算与移动类别修复。
数据为284敌人、101候选组、89补位/自选单位、259形态、72名可拥有六星自选。正式招募池仍为114种基础身份。
阿斯卡纶/贝洛内沿用已有自选技能，克莱门莎新增三技能；盟约按本次要求设置。

用户补充确认：保留原始预算，不另外增加上路密度。1000个种子分别核对终极/天灾 R1–13；
R4–7没有空上路，R4上路范围2–5只，R6/7可出现2只强敌。保留这些符合模板预算的低数量情况，修复错算和漏批次。
命令：`node tools/audit-ultimate-waves.mjs 1000 <报告文件>`；这里只验证波次构成，不宣称完成实际通关率测试。

素材：3个默认 Base 模型、阿斯卡纶时装“趋光之暗”的前/后/基建模型。贝洛内/克莱门莎在固定上游版本没有额外时装。
Spine三件套、动画和贴图校验无错误；皮肤目录现有195套额外时装、707个额外/默认Base模型。
浏览器实测三人的皮肤切换和基建动作预览均正常。
