## 因果隔离

研究目录中的ESM加载器只在独立进程中替换源码，保持生产导入URL、数据、种子和场景不变，不回滚工作区。逐个重跑两个变化场景得到：

| 独立进程中的替换 | 两场景的结果 |
|---|---|
| 不替换 | 与新golden完全一致 |
| 恢复旧damage.js，保留新受击格 | 与新golden完全一致 |
| 恢复7个旧受击/位移模块，保留新damage.js | 与迁移前基线完全一致 |
| 仅将roundHalfEven函数换回Math.round | 与迁移前基线完全一致 |
| 仅将边缘内缩常量换回0，保留half-even | 与新golden完全一致 |

因此这两个场景的实质变化可归因于半格落点的取整，而非官方伤害数字标记、边缘内缩、AI经济、干员倍率或盟约数值。半格命中目标不同会继续影响攻击、击杀、后续随机消耗和战斗时长；结果变化不能用作AI输出改善的证据。
